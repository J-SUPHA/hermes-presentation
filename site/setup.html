Set up Hermes Desktop

Five minutes, start to finish.

1
Download & install Get the installer for your OS from the Hermes Desktop page. It sets up the app and CLI together.
2
Open Hermes Launch the desktop app — or run hermes in a terminal. Both are the same agent.
3
Connect Nous Portal Run hermes setup --portal — one login gives you a model plus web search, image gen, TTS and browser tools. Free tier, no card.
4
Start chatting That's it. Hermes remembers you across sessions and learns how you work. Docs: hermes-agent.nousresearch.com/docs

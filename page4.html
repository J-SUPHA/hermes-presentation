Set up Hermes Desktop

Five minutes, start to finish

  1. 1
    Download & install Get the installer for your OS from the Hermes Desktop page. It sets up the app and CLI together.
  2. 2
    Open Hermes Launch the desktop app, or run hermes in a terminal — same agent either way.
  3. 3
    Connect Nous Portal Run hermes setup --portal, then select Opus 5 or GPT-5.6 Astra Pro as your model.
  4. 4
    Start chatting Hermes remembers you across sessions and learns how you work. Full docs at hermes-agent.nousresearch.com/docs.
